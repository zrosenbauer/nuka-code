    Replace consola.info calls with clack.log.info:
    - Line ~73: `consola.info(...)` -> `clack.log.info(...)`
    - Line ~87: `consola.info("Initializing project...")` -> `clack.log.info("Initializing project...")`
    - Line ~110: `consola.info("No .gitignore file found...")` -> `clack.log.info("No .gitignore file found...")`

    Replace consola.prompt with clack.confirm AND add isCancel handling:

    BEFORE (lines ~77-80):
    ```typescript
    return await consola.prompt("Are you in the root of your project?", {
      type: "confirm",
      default: false,
    });
    ```

    AFTER:
    ```typescript
    const result = await clack.confirm({
      message: "Are you in the root of your project?",
      initialValue: false,
    });
    if (clack.isCancel(result)) {
      clack.cancel("Operation cancelled.");
      process.exit(0);
    }
    return result;
    ```

    IMPORTANT: The isCancel check is critical - clack prompts return a cancel symbol when user presses Ctrl+C, not throwing an error. Without this check, the CLI would continue with undefined behavior.
  </action>

    Run `grep "clack\.confirm" src/lib/project.ts` - should return match
    Run `grep "clack\.isCancel" src/lib/project.ts` - should return match
  </verify>
  <done>
