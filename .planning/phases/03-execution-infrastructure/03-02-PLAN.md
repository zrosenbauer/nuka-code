  <name>Task 1: Create core executor implementation</name>
  <files>src/lib/executor/executor.ts</files>
  <action>
Create `src/lib/executor/executor.ts` implementing task execution per RESEARCH.md and CONTEXT.md:

**Imports:**
- pLimit from 'p-limit'
- Types from './types'
- ProgressDisplay from './progress'
- @clack/prompts for dry-run logging

**Constants:**
- DEFAULT_CONCURRENCY = 4 (per RESEARCH.md)

**Error Translation (per CONTEXT.md):**
Create `translateError(error: Error): string` function:
- ENOENT -> "Directory not found"
- EACCES -> "Permission denied - try running with sudo"
- EBUSY -> "Files are in use by another process"
- EPERM -> "Operation not permitted"
- Default -> "An unexpected error occurred"

**Main execute() function:**
```typescript
async function execute(
  tasks: Task[],
  options: ExecutorOptions
): Promise<ExecutionSummary>
```

Implementation:
1. If options.dryRun is true:
   - Call executeDryRun(tasks) and return early with noop summary

2. Create ProgressDisplay instance
3. Record startTime = Date.now()

4. If options.mode === 'sequential':
   - Run all tasks sequentially via executeSequentially()
5. Else (auto mode):
   - Separate tasks: parallelTasks (parallelSafe=true), sequentialTasks (parallelSafe=false)
   - Run parallel tasks first via executeParallel()
   - Then run sequential tasks via executeSequentially()

6. Return ExecutionSummary with results, totalTime, cancelled status

**executeParallel() function:**
Per RESEARCH.md Pattern 3 and Pattern 7:
- Create pLimit with options.concurrency (or DEFAULT_CONCURRENCY)
- Create internal AbortController for fail-fast
- Combine with options.signal using AbortSignal.any() (Node 20+ per RESEARCH.md)
- Map tasks through limit(), checking abort before each
- On task failure: call internal controller.abort() (fail-fast per CONTEXT.md)
- Update progress display after each task
- Return array of TaskResult

**executeSequentially() function:**
- Loop through tasks
- Check abort before each
- Execute task with signal
- On failure: stop immediately (fail-fast)
- Update progress display after each
- Return array of TaskResult

**executeDryRun() function:**
Per RESEARCH.md Pattern 6:
- Log "Dry run - no changes will be made:"
- For each task: log task.describe() output (action: target)
- Return empty ExecutionSummary with noop results

**Error handling throughout:**
- Wrap task.execute() in try/catch
- Use translateError() for user-friendly messages
- Tasks returning noop=true should log warning per CONTEXT.md ("nothing to clean")

Export: execute function only (other functions are internal)
